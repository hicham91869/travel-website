# 🌍 TravelPro - Professional Travel Booking Website

## 📌 Project Description
TravelPro is a modern and responsive travel booking web application built using **React.js** and **Bootstrap**.  
It allows users to explore destinations, book trips, manage favorites, and calculate total travel services including flights, hotels, and car rentals.

The project focuses on delivering a **professional UI/UX**, smooth user experience, and real-world booking features.

---

## 🚀 Features

- ✈️ Book Flights
- 🏨 Book Hotels
- 🚗 Book Car Rentals
- 💰 Total Service Price Calculation (Flight + Hotel + Car)
- ❤️ Favorites System
- 🔐 Authentication System (Login / Protected Routes)
- 📄 Booking Confirmation Page (Invoice Style)
- 🔎 Advanced Filters (Price, Country)
- 📱 Fully Responsive Design

---

## 🛠️ Technologies Used

- React.js
- React Router DOM
- Bootstrap 5
- JavaScript (ES6)
- LocalStorage (for data persistence)
